  Ideas 1,2,4,5,6 — Definitional Ablation:
    These problems are inexpressible in a static graph model:

    Idea 1 (STS Triage): Temporal betweenness centrality requires
      cross-window path enumeration. A single merged graph computes
      static betweenness that misses window-ordering constraints.

    Idea 2 (Blind Spots): A static graph sees all nodes at all
      times, reporting 0% blind spots — a false sense of security.
      Temporal analysis reveals the true blind-spot ratio.

    Idea 4 (CVE Lifecycle): Full-graph static reachability pairs
      overestimate the active attack surface by ignoring lifecycle
      states (pre-disclosure, exploit-available, patched).

    Idea 5 (Min Coverage): The merged non-temporal graph has fewer
      edges than the temporal path set. A static ILP would find a
      smaller cover set that misses temporal paths entirely.

    Idea 6 (Persistence): Cross-window vulnerability persistence
      requires tracking node presence across multiple observation
      windows. A single-window static model has no mechanism
      to represent exposure trajectories or chronic risk.
