========================================================================
  KEY FINDINGS FOR PAPER
========================================================================

  1. At 40% alert loss, TAG-based inference provides
     probabilistic regional localization rather than exact
     point prediction: 8.9% top-3 accuracy
     with mean topological error of 3.00 hops.
     The attack graph prior narrows the attacker to a smaller
     structural region even with substantial observation gaps.

  2. At 60% sparsity, TAG does not beat random on exact-match
     accuracy (2.1% vs 1.2%).
     However, TAG reduces median topological error from
     4.00 to 2.50 hops
     (1.50 hops closer on average).
     -> The defensible contribution is topology-aware narrowing,
        not exact endpoint recovery.

  3. TAG inference vs Last-Seen heuristic at 60% sparsity:
     TAG exact: 2.1%  |  Last-Seen exact: 30.3%
     TAG dist:  2.50  |  Last-Seen dist:  3.00
     TAG is topologically closer even when not exactly right.

  4. Mean belief assigned to true position: 0.0381
     (Random baseline: 0.0143)
     -> TAG redistributes probability mass toward the correct
        region of the graph, supporting calibrated localization.

  5. Exact point recovery remains below 50% from the first
     non-zero sparsity level tested (20%).
     This method should therefore be framed as regional
     localization, not reliable exact attacker tracking.

  6. Evaluated on 23 independent attack sequences
     (159 total alerts), 5 trials per sparsity rate.
     Results are averaged over 4 non-zero
     sparsity levels x 5 trials = 20 experiments per source.

  7. TEMPORAL ABLATION (Static vs Temporal Transition Matrix):
     At 60% sparsity:
     Temporal TAG dist: 2.50  |  Static TAG dist: 35.50
     Temporal TAG exact: 2.1%  |  Static TAG exact: 0.1%
     -> Temporal weighting reduces median distance by 33.00 hops (93.0%).
        Stripping temporal ordering from the transition matrix
        causes belief to diffuse more uniformly, confirming that
        temporal path ordering is responsible for localization.

  -> No existing IDS can estimate attacker progress from
     sparse alerts using attack graph topology as a prior.
     This is best interpreted as probabilistic regional
     localization under partial observability, with measurable
     distance reduction even when exact recovery is weak.
